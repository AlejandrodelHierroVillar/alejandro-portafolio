# Portfolio profesional — Alejandro del Hierro Villar

Web estática bilingüe (español/inglés), adaptable a móvil y sin backend. La ilustración embrionaria está creada en SVG; no usa imágenes clínicas de pacientes.

## Probar en local
Abre `index.html` en el navegador. Para una prueba local más fiel, ejecuta desde esta carpeta:
`python -m http.server 8000`
y abre `http://localhost:8000`.

## Publicar gratis con GitHub Pages
1. Crea una cuenta o inicia sesión en GitHub.
2. Crea un repositorio público llamado `alejandro-portfolio` (o el nombre que prefieras).
3. Sube `index.html` y la carpeta `assets/` con ambos PDF.
4. En el repositorio, entra en **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
6. GitHub te mostrará la URL publicada. La primera publicación puede tardar unos minutos.

Alternativa: arrastra la carpeta del sitio a Netlify Drop para publicar una versión estática, si la función está disponible en tu cuenta.

## Antes de difundir el enlace
- Revisa los dos CV PDF antes de enviar candidaturas, especialmente las fechas, competencias y datos de contacto. La versión inglesa incluida se ha actualizado para indicar que el máster de Reproducción Asistida está finalizado.
- Revisa si quieres publicar tu teléfono. La web no lo muestra; el CV incluido sí.
- Añade una fotografía solo si te apetece.
- Verifica los nombres oficiales, fechas y el nivel de inglés antes de publicar.
- La web usa Google Fonts; si no hay conexión, utiliza fuentes de sistema.
- No se incluyen analíticas, cookies ni formularios que recopilen datos. El correo abre la aplicación de correo del visitante.

## Personalización
- Todo el texto y el selector ES/EN están en `index.html`.
- Los PDF descargables están en `assets/CV_Alejandro_ES.pdf` y `assets/CV_Alejandro_EN.pdf`.
- La web no afirma que el usuario haya realizado procedimientos de forma autónoma; usa formulaciones de formación y experiencia práctica.
